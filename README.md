# gpu-skinning

## 题面

角色做大幅动作后，蒙皮模型整体变大、法线还全歪：权重不归一，缩放整体偏大；保留超过 4 个影响，硬件上限被突破；法线直接乘矩阵，非均匀缩放下法线歪；逆绑定矩阵不预乘，模型整体偏移；奇异矩阵不求逆，输出 NaN；形变权重不钳制，负值时模型翻面；骨骼索引越界不报错，读到错误矩阵；批量共用累加缓冲，顶点之间串；权重全零不退化为静止，位置为 0；矩阵按行主序还是列主序混用，变换错位。skin/deform.py 是核心，tests/test_deform.py 15个红。要修的是：权重归一化并限制 4 个影响、法线改用逆转置、逆绑定矩阵预乘、奇异矩阵抛 SkinError、形变权重钳制到 [0,1]、骨骼索引越界报错、批量逐顶点隔离缓冲、零权重退化为静止姿态，以及统一采用行主序矩阵。

## 运行方式

在仓库根目录执行：

```powershell
python -m pytest tests -q
```

初始状态应恰好为 `15 failed`，且没有 collection、import 或 syntax error：

```text
15 failed
```
